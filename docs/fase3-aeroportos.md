# Fase 3 — Aeroportos novos: lista para aprovação

Fonte: OurAirports (domínio público), baixado em 2026-09-24. Critério: todos os aeroportos brasileiros com código IATA e voo regular na base, mais 8 internacionais.

- **Hoje o jogo tem 26 aeroportos.** Com esta lista, passa a ter **145** (119 novos). Os 26 atuais não mudam, e as coordenadas deles conferem com a base.
- **Porte (1 a 10):** estimativa minha pela ordem de grandeza do movimento anual de passageiros (≥ 15 mi → 9, 6–15 → 7, 3–6 → 6, 1,5–3 → 5, 0,8–1,5 → 4, 0,4–0,8 → 3, 0,15–0,4 → 2, abaixo → 1). Pode corrigir à vontade.
- **Pista curta:** aeroportos que a base classifica como pequenos. Só recebem aviões de pequeno porte (Caravan, PC-12, Twin Otter). Para medir a pista de verdade, dá para usar o arquivo de pistas da mesma base (`runways.csv`, ~4 MB) se você autorizar o download.
- **Hubs para fundar a companhia:** proponho liberar qualquer aeroporto doméstico de porte ≥ 3 (cerca de 50) e, no modelo Pequeno porte, também os de porte 1 e 2. A dificuldade continua pelo porte, e a escolha vira uma busca.
